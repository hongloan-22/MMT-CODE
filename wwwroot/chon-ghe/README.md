# Giao diện sơ đồ ghế Smartbus

## Thư mục
`wwwroot/chon-ghe/`

## Chạy thử
Mở trực tiếp:
`wwwroot/chon-ghe/index.html`

Hoặc chạy ASP.NET Core rồi truy cập:
`/chon-ghe/index.html`

## Ghi chú
- `script.js` đang dùng dữ liệu ghế mẫu để demo UI.
- `available`: còn trống
- `booked`: đã đặt
- `unavailable`: không bán
- Có thể chọn tối đa 5 ghế.
- Giá demo: 120.000đ/ghế.
- Khi tích hợp BE, thay mảng `seats` bằng dữ liệu trả về từ API/database.
